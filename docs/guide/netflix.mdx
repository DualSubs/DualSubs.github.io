# 🇳 Netflix

:::info ℹ️ 用前须知

* 由于 Netflix 已为关键域名固定证书（禁止MitM），本脚本仅能于`兼容模式`下提供双语翻译字幕
  * 兼容模式: 指无法检测字幕语言，无法在 Netflix 中生成双语字幕选项，仅`翻译字幕`模式可用

:::

## 简介
详见[🍿 DualSubs: 🔣 Universal#简介](./universal#简介)

## 使用说明
* 基础: 直接使用（采用默认配置）
  * 默认主语言`自动（AUTO）`，副语言`中文（自动）（ZH）`
  * 总是将当前所选字幕替换为双语字幕
  * `翻译器`默认使用`Google翻译`进行字幕翻译，将字幕按127句为单位划分，进行整段翻译。
* 个性化设置: 使用[在线设置面板](https://dualsubs.github.io/settings/)
  * 先安装 Universal 提供的共用存储功能，再进入对应插件及「合成器」「翻译器」「外部源」面板调整设置。
  * 入口步骤、配置优先级、设置项与默认值见[偏好面板](./settings)。默认优先使用在线面板或 BoxJs 保存的配置。
* 模块／插件参数: 使用 `Loon` 设置面板或 `Surge` 参数设置等功能
  * 如需优先使用这些参数，将「[储存] 配置类型」设为「插件配置优先」（`Storage=Argument`）。
* BoxJs: 仍可配置相同的持久化设置，安装与订阅方法见 [BoxJs 指南](./box-js)。
