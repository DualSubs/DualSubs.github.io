# ▶️ YouTube (Music)
:::info ℹ️ 用前须知

`tvOS`上的`YouTube app`所使用的`www.youtube.com`不可以 MitM  
故本作品不适用于`tvOS`上的`YouTube app`  

:::

## 简介
* 为 YouTube 解锁`字幕`-`自动翻译`全语言选项，选择任一`自动翻译`语言，即为`字幕`+`自动翻译`双语字幕
* 为 YouTube Music 添加双语翻译歌词

## 使用说明
* 基础: 直接使用（采用默认配置）
  * 在播放器`字幕`-`自动翻译`中任选一种语言，即为此语言与原语言双语字幕
  * 支持默认开启双语字幕
    * 第二语言为上次用户所使用的翻译语言
    * 可在 YouTube 在线面板关闭「[字幕] 自动显示」；目标语言在播放器的「自动翻译」中选择
  * 支持任意两种语言字幕合成
    * 第一语言为上次用户所使用的原语言
* 个性化设置: 使用[在线设置面板](https://dualsubs.github.io/settings/)
  * 先安装 Universal 提供的共用存储功能，再进入对应插件及「合成器」「翻译器」「外部源」面板调整设置。
  * 入口步骤、配置优先级、设置项与默认值见[设置指南](./settings)。默认优先使用在线面板或 BoxJs 保存的配置。
* 模块／插件参数: 使用 `Loon` 设置面板或 `Surge` 参数设置等功能
  * 如需优先使用这些参数，将「[储存] 配置类型」设为「插件配置优先」（`Storage=Argument`）。
* BoxJs: 仍可配置相同的持久化设置，安装与订阅方法见 [BoxJs 指南](./box-js)。

## 功能列表
1. 支持`Web端`和`移动端`的`播放器`全翻译语言选项解锁
2. 支持`Web端`和`移动端`有字幕视频的`自动翻译`及`自动生成`双语
   * 选择任意语言`普通字幕`后，若已开启自动显示并有目标语言记录，会沿用该语言；字幕处理方式由 YouTube 面板的「[字幕] 启用类型」决定
   * 当选择`自动翻译`中的`翻译字幕`时，双语字幕分别为`原语言`及`目标语言`
3. 支持默认开启双语字幕
   * 第二语言为上次用户所使用的翻译语言
   * 可在 YouTube 在线面板关闭「[字幕] 自动显示」；目标语言在播放器的「自动翻译」中选择
4. 支持任意两种语言字幕合成
   * 第一语言为上次用户所使用的原语言
5. `自动翻译`语言选项列表现在为双语列表
